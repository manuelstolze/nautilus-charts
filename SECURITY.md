# Security Policy

## Reporting a vulnerability

Do not report a security vulnerability in a public issue or pull request. Use GitHub's private vulnerability report form on this repository's **Security** tab.

Before making this repository public, the owner must enable private vulnerability reporting in the repository settings and confirm that the form is available. See [GitHub's setup guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).

If the form is not available, do not post vulnerability details publicly. Ask the maintainer for a private reporting route.
