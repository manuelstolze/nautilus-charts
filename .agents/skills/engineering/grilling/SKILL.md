# Grill a plan or idea

Ask direct questions that expose choices the owner must make. Continue until the owner can state a clear, testable decision.

## Explore first

Read the relevant instructions, specification, and code. Use what is already known to remove questions that do not need the owner's answer. Ask only about choices that affect scope, requirements, acceptance, risk, or non-goals.

## Ask in rounds

1. Ask every question whose prerequisites are already clear. Keep each question about one decision.
2. Give 2–4 concrete choices. Put the recommended choice first and say why in one short sentence.
3. Offer the owner a way to enter a different answer. Use multiple choice only when choices can apply together.
4. Wait for the owner's answers before asking questions that depend on them.
5. Reflect the key decisions back in one or two short lines. Correct any mismatch before continuing.

Use the available user-question tool. If no such tool is available, ask numbered questions in plain text and wait for the owner to answer.

## Finish when

The owner has settled the goal, scope, requirements, acceptance checks, constraints, risks, and non-goals. Record unresolved points that do not block the decision. Do not turn an assumption into an approved requirement.
